# 물때

**물때** 는 물이 드나드는 **때**, 곧 딱 맞는 시점을 뜻합니다.

수강신청 **오픈 시각에 맞춰 신청 버튼 활성화를 감지하고 신청서/결제 화면까지
열어주는** 개인용 도구입니다.

**결제는 사람이 합니다.** 이 프로그램은 결제 버튼을 누르지 않습니다.

---

## 내려받기

| 파일 | 내용 |
|---|---|
| [**mulddae-setup.exe**](../../releases/latest/download/mulddae-setup.exe) | 설치 프로그램 (약 69MB) |
| [**사용 설명서 (PDF)**](../../releases/latest/download/mulddae-manual-ko.pdf) | 화면 캡처와 함께 순서대로 설명 |

처음이시면 **PDF 설명서를 먼저 보세요.** 화면 그림이 있습니다.

Windows 10/11 64비트. 관리자 권한 필요 없습니다.

> SmartScreen 경고가 뜹니다. 코드 서명이 없어서입니다.
> **추가 정보 → 실행** 으로 진행하세요.

## 쓰는 순서

1. **아이디·비밀번호**와 **신청할 반**을 넣고 [설정 저장]
2. **[반 찾기]** 로 반을 고릅니다 — 고른 순서가 우선순위입니다
3. **[사이트에서]** 로 오픈 시각을 가져옵니다 — 달마다 바뀝니다
4. **[2. 타깃 점검]** 으로 자리가 있는지 확인
5. 오픈 10분 전 **[3. 실전 시작]**

잡히면 결제 화면이 열립니다. **결제는 직접 하세요.**

> 카드 결제창은 이 프로그램이 띄우는 브라우저에서 열리지 않습니다.
> **[결제 주소 복사]** 로 주소를 복사해 평소 쓰는 크롬에 붙여 넣으세요.

### 두 가지 신청 방식

- **하나만** — 먼저 결제창에 닿은 한 곳만 남기고 나머지는 멈춥니다.
- **전부 신청** — 열린 반 전부 신청하고 무엇을 결제할지 직접 고릅니다.

어느 쪽이든 신청은 **동시에** 나갑니다. 그래서 동시에 성공하면 신청이 여러 건
생길 수 있습니다. **결제하지 않을 건은 반드시 직접 취소하세요.**
그래야 다른 신청자가 그 자리를 잡을 수 있습니다.

## 이 도구가 지키는 선

만들면서 코드로 못박은 제약입니다.

| 원칙 | 이유 |
|---|---|
| **상태 확인은 읽기전용 조회만** | 신청 요청을 상태 확인용으로 반복하면 쓰레기 신청 레코드가 쌓이고 자리를 물게 됩니다 |
| **신청 요청은 반당 1회 성공** | 중복 신청은 본인 결제 혼선 + 다른 신청자 자리 점유로 이어집니다 |
| **요청 간격 제한** (반당 초당 2회 이하) | 오픈 직전에 서버를 두드리면 차단당하고, 사이트에도 부담입니다 |
| **결제는 자동화하지 않음** | 금전 확정은 사람의 판단 영역입니다 |
| **대기열이 켜지면 우회하지 않음** | 선착순 대기열이 뜨면 그대로 두고 사람에게 넘깁니다 |

## 잘 안 될 때

| 화면에 나오는 말 | 뜻과 대처 |
|---|---|
| `브라우저 없음` | **브라우저 내려받기** 버튼을 누르세요 |
| `로그인 실패` | 아이디/비밀번호를 다시 확인하세요 |
| `이미 정원 마감` | 그 반은 이미 찼습니다. 표의 대안 후보로 바꾸세요 |
| `신규 접수기간이 설정과 다르다` | **[사이트에서]** 로 오픈 시각을 다시 가져오세요 |
| `요청이 차단됐다 (HTTP 429/403)` | 요청이 막혔습니다. 열린 브라우저 탭에서 **직접 F5 + 신청** 하세요 |
| `버튼 상태를 3회 연속 판정하지 못했다` | 사이트 화면이 예상과 다릅니다. 직접 진행하세요 |
| `선착순 대기열이 켜졌다` | 도구는 일부러 우회하지 않습니다. 대기창을 그대로 두세요 |
| `신청 요청 결과가 불확실하다` | 마이페이지 > 신청내역을 직접 확인하세요 |

**도구를 믿지 못할 상황이면 기다리지 말고 직접 하세요.** 도구가 띄운 탭은 이미 로그인돼
있으므로 F5 후 바로 신청 버튼을 누를 수 있습니다. 같은 계정으로 다른 브라우저에서
동시에 로그인해도 서로 세션이 끊기지 않습니다(확인함).

## 못 잡았을 때

실행이 끝나면 **진단 리포트**가 만들어집니다. **[기록 · 진단]** 버튼을 누르면
그 파일이 선택된 채로 폴더가 열립니다.

버튼이 언제 어떤 상태로 보였는지, 감지가 몇 ms 걸렸는지, **다음 달에 무엇을
바꾸면 되는지**가 적혀 있습니다.

---

## 알아둘 것

- **감시 중에는 컴퓨터가 켜져 있어야 합니다.** 절전으로 들어가면 멈춥니다.
- 아이콘을 다시 누르면 **먼저 떠 있던 창이 닫힙니다.** 감시 중에는 누르지 마세요.
- 설치 폴더의 `logs/` 에 실행 기록이, `out/shots/` 에 신청 직후 화면 캡처가 남습니다.
  **캡처에는 신청자 이름·연락처 같은 개인정보가 들어 있으니** 끝나면 지우세요.
- 재설치해도 설정과 아이디/비밀번호는 지워지지 않습니다.
- 제거: 제어판 → 프로그램 추가/제거. 설정과 로그는 남으니 필요하면 폴더째 지우세요.

## 제한

- 특정 수강신청 페이지 구조에 맞춰 만들었습니다. 사이트가 개편되면 동작하지 않을 수 있습니다.
- 코드 서명이 없어 SmartScreen/백신이 경고할 수 있습니다.
- 본인 계정으로 본인(가족) 신청에 쓰는 것을 전제로 만들었습니다.
