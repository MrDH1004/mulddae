# hinuri 수강신청 오픈런

휘경이문누리종합사회복지관([hinuri.kr](https://hinuri.kr)) 수강신청 **오픈 시각에 맞춰
신청 버튼 활성화를 감지하고 신청서/결제 화면까지 열어주는** 개인용 도구입니다.

**결제는 사람이 합니다.** 이 프로그램은 결제 버튼을 누르지 않습니다.

---

| 파일 | 내용 |
|---|---|
| [**hinuri-swim-setup.exe**](../../releases/latest/download/hinuri-swim-setup.exe) | 설치 프로그램 (약 69MB) |
| [**사용 설명서 (PDF)**](../../releases/latest/download/hinuri-swim-manual-ko.pdf) | 화면 캡처와 함께 순서대로 설명 (5쪽) |

처음이시면 **PDF 설명서를 먼저 보세요.** 아래 내용과 같지만 화면 그림이 있습니다.

Windows 10/11 64비트. 관리자 권한 필요 없습니다.

> SmartScreen 경고가 뜹니다. 코드 서명이 없어서입니다.
> **추가 정보 → 실행** 으로 진행하세요.

## 설치

1. `hinuri-swim-setup.exe` 실행
   - 파일 하나를 푸는 데 **1~2분** 걸립니다. 창이 안 떠도 기다리세요.
2. 설치 위치 확인 → **설치**
   - 설치 마지막에 브라우저(Chromium, 약 150MB)를 자동으로 내려받습니다.
3. 설치 후 바탕화면/시작 메뉴의 바로가기로 실행

기본 설치 위치: `%LOCALAPPDATA%\Programs\hinuri-swim`

---

## 사용법

실행하면 창이 뜹니다. 위쪽에 설정, 아래쪽에 버튼 4개가 순서대로 있습니다.

### 1) 먼저 설정

| 항목 | 넣을 값 |
|---|---|
| 아이디 / 비밀번호 | **본인의** hinuri.kr 계정 |
| 타깃 pr_seq | 신청할 반 번호 (쉼표로 구분, 예: `1501, 1503, 1504`) |
| 모드 | `first-win` 또는 `all-attempt` (아래 설명) |
| 오픈 시각 | 신규 접수 시작 시각 (예: `2026-10-28T09:00:00+09:00`) |
| 종료 시각 | 언제까지 시도할지 (예: `2026-10-28T09:10:00+09:00`) |

입력 후 **설정 저장**.

아이디/비밀번호는 이 PC 의 설치 폴더에만 저장되고, 로그에는 마스킹되어 기록됩니다.

### 2) 버튼 순서대로

| 버튼 | 하는 일 |
|---|---|
| **1. 잔여석 확인** | 전체 목록을 잔여석 많은 순으로 보여줍니다. 여기서 `pr_seq` 를 고르세요 |
| **2. 타깃 점검** | 내 타깃이 이미 만석인지, 접수기간이 맞는지 확인합니다 |
| **3. 예행연습** | 로그인·감시까지 실제로 하고 **신청만 생략**합니다. 실제 신청은 안 생깁니다 |
| **4. 실전 시작** | 실제 신청. 오픈 10분 전쯤 눌러두면 됩니다 |

**오픈 당일 권장 순서**: 오픈 20분 전 `1` → `2` 로 타깃 확인 → 10분 전 `4` 실행 →
잡히면 결제 화면이 앞으로 나옵니다 → **직접 결제**

### 두 가지 모드

- **first-win** — 여러 반 중 가장 먼저 열린 **한 곳만** 신청하고 나머지는 즉시 중단합니다.
- **all-attempt** — 열린 반 **전부** 신청서까지 띄우고 무엇을 결제할지 직접 고릅니다.
  이 모드는 여러 자리를 동시에 잡아두게 되므로, **결제하지 않을 건은 반드시 직접 취소**하세요.
  그래야 다른 신청자가 그 자리를 잡을 수 있습니다.

## 이 도구가 지키는 선

만들면서 코드로 못박은 제약입니다.

| 원칙 | 이유 |
|---|---|
| **상태 확인은 읽기전용 조회만** | 신청 요청을 상태 확인용으로 반복하면 쓰레기 신청 레코드가 쌓이고 자리를 물게 됩니다 |
| **신청 요청은 반당 1회 성공** | 중복 신청은 본인 결제 혼선 + 다른 신청자 자리 점유로 이어집니다 |
| **요청 간격 제한** (반당 초당 2회 이하) | 오픈 직전에 서버를 두드리면 차단당하고, 사이트에도 부담입니다 |
| **결제는 자동화하지 않음** | 금전 확정은 사람의 판단 영역입니다 |
| **대기열이 켜지면 우회하지 않음** | 선착순 대기열이 뜨면 그대로 두고 사람에게 넘깁니다 |

## 잘 안 될 때

| 화면에 나오는 말 | 뜻과 대처 |
|---|---|
| `브라우저 없음` | **브라우저 내려받기** 버튼을 누르세요 |
| `로그인 실패` | 아이디/비밀번호를 다시 확인하세요 |
| `이미 정원 마감` | 그 반은 이미 찼습니다. 표의 대안 후보로 바꾸세요 |
| `신규 접수기간이 설정과 다르다` | **오픈 시각** 설정이 사이트와 다릅니다. 사이트 값에 맞추세요 |
| `요청이 차단됐다 (HTTP 429/403)` | 요청이 막혔습니다. 열린 브라우저 탭에서 **직접 F5 + 신청** 하세요 |
| `버튼 상태를 3회 연속 판정하지 못했다` | 사이트 화면이 예상과 다릅니다. 직접 진행하세요 |
| `선착순 대기열이 켜졌다` | 도구는 일부러 우회하지 않습니다. 대기창을 그대로 두세요 |
| `신청 요청 결과가 불확실하다` | 마이페이지 > 신청내역을 직접 확인하세요 |

**도구를 믿지 못할 상황이면 기다리지 말고 직접 하세요.** 도구가 띄운 탭은 이미 로그인돼
있으므로 F5 후 바로 신청 버튼을 누를 수 있습니다. 같은 계정으로 다른 브라우저에서
동시에 로그인해도 서로 세션이 끊기지 않습니다(확인함).

## 알아둘 것

- **감시 중에는 컴퓨터가 켜져 있어야 합니다.** 절전으로 들어가면 멈춥니다.
- 설치 폴더의 `logs/` 에 실행 기록이, `out/shots/` 에 신청 직후 화면 캡처가 남습니다.
  **캡처에는 신청자 이름·연락처 같은 개인정보가 들어 있으니** 끝나면 지우세요.
- 재설치해도 설정과 아이디/비밀번호는 지워지지 않습니다.
- 제거: 제어판 → 프로그램 추가/제거. 설정과 로그는 남으니 필요하면 폴더째 지우세요.

## 제한

- 휘경이문누리종합사회복지관 수강신청 페이지 구조에 맞춰 만들었습니다. 사이트가 개편되면
  동작하지 않을 수 있습니다.
- 코드 서명이 없어 SmartScreen/백신이 경고할 수 있습니다.
- 본인 계정으로 본인(가족) 신청에 쓰는 것을 전제로 만들었습니다.
